# Napics 社区插件源

> 灰色/高风险插件的独立分发仓库，与主仓库隔离。

## 插件列表

### 搜索类
| 插件 ID | 名称 | 说明 |
|---------|------|------|
| search-bt-direct | BT 直搜源包 | 12 个 BT 直搜源（Bitsearch/Nyaa/蜜柑等） |
| search-pan | 网盘搜索 | 9 个网盘源聚合搜索 |
| search-prowlarr | Prowlarr | BT/PT 聚合搜索 |

### RSS 类
| 插件 ID | 名称 | 说明 |
|---------|------|------|
| rss-anime | 动画 RSS 源包 | 蜜柑/Nyaa/ACG.RIP/Bangumi Moe/动漫花园 |
| rss-tv-movie | 影视 RSS 源包 | EZTV/YTS/Prowlarr RSS |

### 元数据类
| 插件 ID | 名称 | 说明 |
|---------|------|------|
| metadata-douban | 豆瓣 | 中文元数据补充 |

### 下载/存储类
| 插件 ID | 名称 | 说明 |
|---------|------|------|
| download-openlist | OpenList/Alist | 网盘离线下载 |
| storage-openlist | OpenList 浏览 | 网盘挂载浏览 |

### 功能类
| 插件 ID | 名称 | 说明 |
|---------|------|------|
| feature-subscribe | 订阅追更 | RSS 定时轮询 + 自动下载新集 |

## 使用方式

1. 在 Napics 插件中心点击"添加插件源"
2. 输入本仓库地址：`https://github.com/icatmiumiu/plugins-of-napics`
3. 浏览并安装需要的插件

## 安全提示

⚠️ 社区插件可能包含网络爬虫代码，请确认你了解相关风险后再安装。
